## Demo 1: 经营分析闭环

### 上传材料

- `channel-q2-brief.docx`
- `sales-pipeline-q2.csv`

### 选择员工

- 主员工: 财务经营分析师
- 接力员工: 法务合规顾问、运营增长顾问

### 推荐提示词

```text
请基于我上传的 Q2 经营简报和销售管道数据, 按角色接力完成:
1. 财务经营分析师: 判断收入增长质量、毛利下降、投诉上升和续约率下降的经营含义, 输出 3 条管理动作。
2. 法务合规顾问: 判断代理商整改、冻结新增项目、折扣审批链路可能涉及的合同/合规风险, 输出 3 条待确认问题。
3. 运营增长顾问: 输出下季度渠道分级、SLA、投诉闭环和续约挽回计划。

最终请生成:
- Markdown 管理层摘要
- 风险表格
- 30 天行动清单
- 一个 HTML 管理层看板, 放在 html 代码块中
```

### 验收点

- 聊天区 Markdown 表格正常渲染。
- 右侧证据页能看到文件、Skill、记忆。
- 总结页能生成会话级总结。
- 输出物包含 Markdown/HTML, 可下载, 可归档。

## 常见客户问题回答

### 这和 ChatGPT 有什么区别?

ChatGPT 主要是对话工具。OpenAtlas 把对话包装成企业任务: 有员工角色、Skill、文件、记忆、权限、审计和交付物。企业买的是可控的任务闭环, 不是一个聊天框。

### Skill 是不是黑盒?

不是。Skill Market 展示能力说明、适用员工、输入输出示例、风险等级、版本和健康状态。每轮对话右侧会显示实际注入/调用的 Skill。

### 文件会不会被其他用户看到?

不会。文件按租户、用户、会话存储, 后端 API 做租户和用户校验。演示时可以打开隔离页、审计日志和文件列表证明。

### 结果不准确怎么办?

平台不承诺模型永远正确, 但会提供证据链、引用材料、任务状态、人工补充入口和归档记录, 让错误可发现、可追溯、可纠正。
