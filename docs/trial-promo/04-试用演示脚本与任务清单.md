# OpenAtlas 试用演示脚本与任务清单

## 演示目标

让试用用户在 15-20 分钟内理解:

- OpenAtlas 不是普通聊天框。
- 数字员工可以处理真实业务任务。
- 任务过程有反馈，输出有交付物。
- 文件、Skill、员工、会话、交付物可以被管理。

## 演示结构

### 0-2 分钟: 说明定位

话术:

```text
OpenAtlas 是企业数智员工工作台。你不是从空白聊天框开始，而是把任务交给不同岗位的数字员工。系统会保留任务进展、文件上下文、Skill 使用和最终交付物。
```

强调四个关键词:

- 员工可用
- 能力可信
- 任务闭环
- 企业可管

### 2-5 分钟: 首页和行政小六

演示:

1. 打开工作台。
2. 在输入框输入:

```text
@行政小六 我想做一份机器人行业市场调研报告，应该找谁？
```

看点:

- 用户可以不懂 Prompt，先让行政小六分诊。
- 首页输入框支持 `@员工`。
- 默认 `Enter` 发送，`Shift+Enter` 换行；中文输入法组合态不会误发送。

### 5-10 分钟: 单员工任务

选择员工:

```text
市场竞品研究员
```

输入:

```text
请调研机器人行业市场，输出市场规模、主要玩家、增长驱动、风险和销售切入点。请用 Markdown 表格和要点展示。
```

看点:

- 聊天区有任务进展。
- Markdown 表格可读。
- 右侧栏能看到任务状态、输入来源和输出物。

### 10-15 分钟: 文件 + 交付物

上传一份 Markdown/TXT/DOCX/PDF 材料。

选择员工:

```text
翻书人 PageTurner
```

输入:

```text
请解析我上传的文档，输出核心观点、章节结构、关键证据、引用片段和一份适合管理层阅读的 Markdown 摘要。
```

看点:

- 文件内容能注入上下文。
- 不应回答“看不到文件”。
- 右侧能查看注入文件和交付物。

### 15-20 分钟: 多员工接力

输入:

```text
请三位员工接力完成一份销售攻坚方案:
@市场竞品研究员 先分析行业和竞品机会。
@销售方案顾问 再生成客户方案和沟通话术。
@财务经营分析师 最后给出报价边界和毛利保护建议。
```

看点:

- 多位员工有 speaker 区分。
- 每位员工只做自己的角色。
- 任务结果可以继续追问、下载或归档。

| T03 | 合同风险审查 | 法务合规顾问 | 风险清单 |

## 演示风险和处理

| 风险 | 处理方式 |
| --- | --- |
| 模型长时间无反馈 | 指出任务会显示运行阶段；可切历史会话查看状态；长任务可继续同步。 |
| 文件解析失败 | 换 TXT/Markdown/DOCX 样例，说明扫描件和复杂表格仍需增强。 |
| 输出太泛 | 追加“请按表格输出，列出依据、风险、建议、下一步动作”。 |
| 工具审批弹出 | 解释这是企业安全控制，高风险动作需要人工确认。 |
| 交付物未出现 | 在聊天中要求“输出完整 HTML/Markdown 交付物”，再查看右侧输出物。 |
