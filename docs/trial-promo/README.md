# OpenAtlas 试用宣发资料包

> 版本: 2026-06-19
>
> 用途: 面向首批试用用户、业务部门负责人、企业内部创新项目和潜在客户的宣发、引导、演示与反馈收集。

## 使用方式

- 对外公开传播: 使用 `01-试用宣发文案包.md`、`02-产品介绍单页.md`、`07-官网落地页文案.md`。
- 试用用户 onboarding: 使用 `03-试用用户操作指南.md`。
- 销售/演示: 使用 `04-试用演示脚本与任务清单.md`。
- 客户答疑: 使用 `05-FAQ与销售答疑.md`。
- 试用复盘: 使用 `06-试用反馈表与成功标准.md`。

## 传播主线

OpenAtlas 不是普通聊天框，而是企业数智员工工作台。用户可以把市场调研、合同审查、经营分析、招聘初筛、会议纪要、文档解析等任务交给不同数字员工处理，过程可追踪，结果可预览、下载、归档。

## 对外一句话

让企业用一支可协作、可追踪、可交付的 AI 数字员工队伍，完成真实业务任务。

## 试用重点

- 员工可用: 不从空白 Prompt 开始，直接选择专业数字员工。
- 能力可信: 看得到本轮注入的文件、Skill、记忆和工具阶段。
- 任务闭环: 输出报告、HTML、表格、清单等可下载交付物。
- 企业可管: 支持权限、租户隔离、审计、运行状态与历史追踪。

## 内外部边界

公开文案不放真实账号和密码。账号、试用入口、演示素材只放在内部操作指南中，并按试用批次替换。
