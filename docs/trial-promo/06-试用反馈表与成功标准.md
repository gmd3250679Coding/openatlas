## 2. 试用成功标准

### 单个用户成功标准

- 至少完成 3 个真实任务。
- 至少生成 1 个可下载交付物。
- 至少上传并成功解析 1 个文件。
- 能说清楚“哪个员工适合哪个任务”。
- 愿意在下周继续试用。

### 团队试点成功标准

- 5 名以上业务用户完成试用。
- 累计完成 20 个以上任务。
- 60% 以上任务产生可复用交付物。
- 至少覆盖 3 类业务场景。
- 主要问题集中在体验优化，而不是主链路不可用。

### 企业试点成功标准

- 管理员能查看用户、员工、Skill、历史、审计和运行状态。
- 权限隔离验证无明显问题。
- 长任务、文件、群聊接力、交付物归档主链路稳定。
- 至少一个部门愿意拿真实脱敏材料继续试点。

## 3. 试用后分层跟进

| 用户类型 | 判断标准 | 跟进动作 |
| --- | --- | --- |
| 高意向 | 生成真实交付物并愿意复用 | 安排 1v1 访谈，收集业务流程和采购关注点 |
| 中意向 | 认可方向但输出需优化 | 收集任务样例，优化员工 Prompt 和 Skill |
| 低意向 | 不理解产品或任务失败 | 回放操作路径，判断是定位问题、体验问题还是能力问题 |
| 管理员 | 关注权限、审计、隔离 | 演示管理后台、审计、运行健康和租户隔离 |
