## 3. 建议试用方式

### 第一步: 从工作台开始

进入工作台后，可以直接在首页输入需求。

推荐输入:

```text
@行政小六 我想做一份机器人行业市场调研报告，应该找哪个员工？
```

如果不确定找谁，直接问行政小六。它会根据任务推荐合适的数字员工。

### 第二步: 指定员工

在输入框中输入 `@`，选择一个员工。

示例:

```text
@市场竞品研究员 调研一下机器人行业市场，输出一份 Markdown 摘要。
```

```text
@法务合规顾问 帮我审查这份合同，输出高/中/低风险清单。
```

### 第三步: 上传文件

支持上传常见办公文件:

- Markdown / TXT
- PDF
- DOCX
- XLSX / CSV
- PPTX
- 图片

快捷方式:

- 粘贴上传: `Command/Ctrl + V`
- 选择附件: `Command/Ctrl + Shift + U`
- 选择图片: `Command/Ctrl + Shift + P`

### 第四步: 发送消息

默认发送方式:

```text
Enter 发送
Shift + Enter 换行
```

中文输入法选词/确认过程中不会触发发送。`Command/Ctrl + Enter` 仍可作为辅助发送方式。

### 第五步: 查看任务进展和交付物

任务执行时，聊天区会出现阶段反馈，例如:

- 正在准备文件上下文
- 正在调度数字员工
- 正在生成回复
- 工具调用 / 审批 / 等待
- 交付物已入库

右侧栏可查看:

- 任务状态
- 输入来源
- 文件和上下文
- 交付物预览与下载
- 会话总结

## 4. 推荐试用任务

### 任务 A: 市场调研

```text
@市场竞品研究员 请调研机器人行业市场，输出市场规模、主要玩家、增长驱动、风险和销售切入点。请用 Markdown 表格和要点展示。
```

### 任务 B: HTML 报告

```text
@投资研究分析师 请生成一份“浪潮数字企业投资分析报告”，要求输出完整 HTML 报告，包含关键指标卡、投资亮点、风险矩阵和结论。
```

### 任务 C: 合同审查

上传合同后输入:

```text
@法务合规顾问 请审查我上传的合同，按高/中/低风险输出风险清单、修改建议和待确认问题，并引用相关条款。
```

### 任务 D: 会议纪要

上传会议记录后输入:

```text
@项目交付经理 请把会议记录整理为会议结论、待办事项、责任人、截止时间、风险和下次会议议题。
```

### 任务 E: 长文档解析

上传论文或长报告后输入:

```text
@翻书人 PageTurner 请解析这份文档，输出核心观点、章节结构、关键证据、可引用片段和我的后续阅读建议。
```

## 5. 反馈重点

试用后请重点反馈:

1. 哪个任务最有价值？
2. 输出物是否能直接用于工作？
3. 文件解析是否准确？
4. 任务进展是否足够清楚？
5. 你是否能理解员工用了哪些文件、Skill 和记忆？
6. 哪些地方让你觉得不稳定、不可信或不好用？
