# OpenAtlas 当前功能清单

版本：`0.2.0-preview.1`

整理日期：2026-09-16

本清单以当前代码入口、数据库模型和 API 为依据。仓库当前包含 25 个前端页面、178 个后端 HTTP 路由、35 个核心数据模型和 13 组浏览器端场景测试。

## 1. 身份与组织

- 登录、注册、当前用户会话。
- 租户、组织单元、用户与管理员角色。
- 权限矩阵覆盖工作区、员工、会话、文件、技能、记忆和管理面。
- 管理员路由与普通用户路由分离。

## 2. 数智员工

- 员工列表、详情、招聘、编辑与停用。
- 岗位说明、运行 Profile、模型、工具集和技能绑定。
- 员工状态与租户运行时健康联动。
- 单员工执行与多员工接力协作。

## 3. 任务、会话与工作流

- 会话创建、历史查询、归档、Fork 和恢复。
- 流式消息、推理摘要、工具事件、限流与后台长任务同步。
- 任务状态机：草稿、运行、等待审批、停滞、失败、完成等。
- 协作工作流、节点运行、步骤事件、检查点、回放和恢复分支。
- 用户离开页面后，后端继续追踪 Hermes run 并同步最终结果。

## 4. 文件与交付物

- 文件上传、列表、工作区访问、在线预览和下载。
- 文本及常用办公文档抽取。
- 交付物登记、版本、重命名、终稿标记、归档和下载。
- 会话、员工、上下文注入与交付物之间保留关联。

## 5. 技能、知识与记忆

- Hermes Skill Hub 浏览、搜索、安装、升级、审计与修复。
- OpenAtlas 技能市场登记、导入、发布、禁用、Fork 和员工绑定。
- Hermes 真实安装状态与 OpenAtlas 治理元数据对账。
- 全局、租户、用户、员工等不同作用域的记忆与绑定。
- 每轮任务可记录实际注入的技能、文件和记忆。

## 6. A2UI 与办公场景

### 创意白板

- 白板创建、读取、更新和删除。
- AI 生成、理解和细化白板内容。
- 内置流程图、UML、架构图、系统设计等 Excalidraw 模板和组件库。

### AI PPT

- 大纲到 Deck Schema 的分段生成。
- HTML 演示渲染、全屏预览与 PPTX 导出。
- 低代码 Designer、对象选择、对齐、图层、撤销/重做、版本保存和恢复。
- 页面级 AI 修改、资料补充、研究、导出兼容性与质量检查。
- 无后端的离线 Demo 与可插拔 Storage / Agent / Research Adapter。

### 公文写作

- 意图识别、字段确认、正文生成、修订和版本管理。
- 在线预览与文档下载。

### 合同审查

- 合同上传、文本抽取、风险审查与问题状态流转。
- 审查版本、风险清单、交付物重新生成、预览和下载。

## 7. 运营与治理

- 个人、租户和系统级仪表盘。
- 作业创建、暂停、恢复和立即执行。
- 审计日志、证据链、运行事件和诊断日志。
- 租户 Hermes Runtime 启停、健康检查与隔离状态。

## 8. 当前发布边界

- `frontend/dist/`、根目录 `dist/`、日志、本地数据库、Playwright 产物和 `.openatlas` 状态不进入源码版本。
- `frontend/public/` 中被产品直接引用的图片、模板和示例属于源资产，应保留。
- `demo-pack/` 只保存可公开的演示数据；真实客户数据不得提交。
- `docs/DELIVERY-*` 与 `docs/SESSION-LOG-*` 仅作历史追溯。

## 9. 后续优先级

1. 把后端单体 API 按领域拆成独立 router/service，降低 2 万行主文件的维护成本。
2. 为会话、运行、审批和交付物定义统一事件 Schema，减少前后端兼容分支。
3. 继续拆分前端大 chunk，优先处理 AI PPT、画布和重型编辑依赖。
4. 为核心 API 增加独立单元/集成测试，减少对全栈 smoke 的依赖。
