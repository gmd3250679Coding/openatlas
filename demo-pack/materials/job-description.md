# 岗位说明: 企业数智员工解决方案顾问

## 岗位职责

- 负责企业客户试点阶段的需求访谈、场景梳理和演示交付。
- 将客户业务流程转化为数智员工、Skill 和协作模板配置。
- 支持财务、法务、销售、HR 等部门完成 AI 任务闭环试点。
- 跟踪试点效果, 沉淀可复用行业方案。

## 必备条件

- 3 年以上企业软件、咨询、销售运营或数据分析经验。
- 能独立撰写客户方案和项目计划。
- 理解企业权限、审计、数据隔离等基础概念。
- 具备良好沟通能力和结构化表达能力。

## 加分项

- 有财务经营分析、合同管理、CRM、BI 或 RPA 项目经验。
- 熟悉大模型应用、AI Agent 或企业知识库产品。
- 能读懂简单 API 文档或数据表。

## 风险提醒

招聘沟通中不得以年龄、性别、婚育、户籍等维度做不当筛选。
